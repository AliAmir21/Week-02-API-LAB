# API Lab — Task 02

This project covers API fundamentals, HTTP/REST, JSON, Python API integration, secure configuration, error handling, timeouts, rate limits, and API-as-a-tool design.

## Setup
From this folder, run:
```bash
python -m pip install -r final_project/requirements.txt
python final_project/src/api_client.py
```

## API
Uses the public demonstration API `https://jsonplaceholder.typicode.com`.
JSONPlaceholder simulates POST/PUT/DELETE responses; those operations do not permanently change a real database.

## Safety
Never commit real API keys. Keep `.env` local and ignored by Git. This project uses only placeholder credentials.
